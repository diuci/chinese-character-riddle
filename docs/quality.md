# 质量门槛（quality）

> 「全网质量最高」不是一句口号，是 `tools/validate.py` 里跑着的规则。
> 任何一条不满足，构建失败。质量差的不要收入——宁可空目录，不塞低质篇目。

## 收录判据（八条）

1. **唯一谜底**——谜底明确、无歧义。歧义谜面剔除，或登记 `data/known-defects.json` 说明为何保留。
2. **解析完备**——每谜必须有「解析」段，给出推演链，不能只给谜底。
3. **来源可溯**——`source` 必填。无来源孤谜不收。
4. **无近似重复**——谜面完全重复或互为子串，须登记 `known-defects.json`，否则拒收。
5. **无低质内容**——低俗、歧义、政治敏感一律拒收（`check-legal.mjs` 与人工审核共同把关）。
6. **难度评级**——`difficulty` 必填且在 1–5。
7. **公版安全**——古典匿名/古早 = 公版；当代作品须署名且卒年 ≤ 当前年 − 50，或来源确证/已授权，否则进 `pending/`。
8. **谜种合法**——`type` 必须取自合法集：拆字 / 会意 / 谐音 / 增损 / 离合 / 典故 / 象形 / 方位 / 数字 / 当代。

## 自检护栏

`python tools/validate.py --selftest` 用 12 个坏样本证明每条护栏真拦得住，
再用 10 个干净样本证明不误报。护栏是摆设就构建失败。

## 宁缺毋滥

谐音、典故等谜种在种子阶段若找不到来源确证、谜底无歧义的高质篇目，就留空目录，
等 M2 补齐。空目录比低质篇目更诚实。
