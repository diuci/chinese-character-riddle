# 数据来源与许可（sources）

七类来源交叉校验，每篇 frontmatter 的 `source` 字段记录来源代号。汇总台账见 [PROVENANCE.md](../PROVENANCE.md)。

| 代号 | 来源 | 许可 | 用途 | 说明 |
|---|---|---|---|---|
| S1 | 古典灯谜/字谜古籍 | 公有领域 | 古典谜面谜底初稿与解析 | 《文虎联珠集》(明)、《文虎偶存》、《玉荷隐语》、《字謎大全》(清) 等 |
| S2 | 网络开放收藏 | 以各自许可为准 | 交叉比对、补漏 | 如 daizhige 集藏·谜语/文虎 等开源谜集 |
| S3 | CC-Riddle 汉字谜语数据集 | 开源 | 校验谜底一致性、补当代高质谜 | HuggingFace 上的汉字谜语问答数据集 |
| S4 | 当代高质量字谜 | CC BY 4.0 / 授权 | 当代优作 | 来源确证或已授权，署名 |
| S5 | 商业站点 | 版权 | **仅比对用字，不复制** | 对照用字是否一致，不搬原文 |

## 公版规则

判定只有一条——**作者卒年 ≤ 当前年 − 50**（《著作权法》自然人作品保护期）。
- 古典匿名谜：记 `era` 年代上限，早已届满。
- 当代署名作者：`data/authors.json` 记卒年，`validate.py` 第 8 项逐篇核验。
- 仍在保护期：不收录原文，登记 `pending/`。
